# PR-08 需求引导增强：验收记录

## 功能边界
- 依据已保存的用户文字，提取**未确认的场景/目标提示**，不能把提示写成工程事实。
- R2 必需外部工况由原有 StageRequirementRegistry/readiness 判定；轴承宽度、径向间隙、材料和润滑剂是可提案设计变量，不成为硬性追问。
- 问题排序随用户关切（温升/高速、重载等）变化；问题保留原因说明。
- 可显式注入 `QuestionRanker`，只能重排确定性问题 ID，不能生成数值、角色、确认或新问题。
- Agent 通过受限工具 `last_user_turn` 读取最近保存的消息，只产生只读问题，所有写入仍走 InteractionService/StateManager。

## 未实现
- 不对无证据的场景或参数作确定判断。
- 不自动确定材料/润滑剂参数值。
- 默认不调用远程 LLM；真实模型需调用方显式接入并提供结构化输出。
- 不新增独立记忆库、规则库或权限系统。
