# PR-09 DesignAgent 策略深化验收

## 本 PR 实现
- 形成具备实际可用性标记的分析计划：表面速度、投影平均比压、最小油膜厚度、热平衡、材料和润滑剂适用性。
- 动态区分已可计算 / 需要设计变量 / 需要外部输入 / 尚无求解器 / 缺审核规则。
- LLM 仅可排序既有分析步骤，不得增添数值阈值、工程 PASS/FAIL 或伪造求解执行。
- 保留来自 ACTIVE 审核表格或可信用户输入的候选值逻辑；缺乏依据时 `INSUFFICIENT_RULES`。
- 候选比较严格要求工程输入版本与专业校核覆盖可比；不具备证据时不得宣布优胜者。

## 明确不做
- 不接 DLAP/EXE、不编造膜厚温度和压力场，不对未审校的草案表格启用 ACTIVE。
- 不实现多目标数值优化、并行候选搜索或另一套 Agent 状态数据库。
- 真实大模型与标准算例仍需独立专业验证。
